Browser benchmark and worker scaling

This page compares React 19.2.4, runtime1, and runtime2 at multiple Go WASM worker counts. The default scaling matrix is 1, 2, 4, and 8 workers for the same off-main-thread chunk-preparation step. It measures browser-visible render and update work through one shared DOM contract while keeping DOM ownership on the main thread, and it now reports both DOM-ready and paint-proxy finish lines instead of one mixed headline. The RT2 scaling section below compares worker batch time directly so frame-quantized paint timings do not hide worker-count differences.
