# v6.1 Windows API parity

Scope: the pinned Wails v3 Windows application capabilities behind typed GWC
desktop contracts. Wails objects do not cross into shared web/Wasm code.
Host configuration, raw JavaScript execution, arbitrary webview navigation and
update installation remain native-host-only. Other operating systems are not
certified by this release.
